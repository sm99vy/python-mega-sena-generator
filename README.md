# 🎲 Gerador de Palpites para a Mega-Sena

Programa desenvolvido em Python para gerar combinações aleatórias de números para jogos da Mega-Sena.

## Funcionalidades

- Definição da quantidade de jogos
- Geração de combinações aleatórias
- Organização dos números sorteados
- Exibição dos jogos no terminal

## Tecnologias

- Python 3
- Módulo `random`

## Conceitos praticados

- Listas
- Números aleatórios
- Módulos da biblioteca padrão
- Laços de repetição
- Organização de dados

## Como executar

```bash
python mega-sena-generator.py
```

## Objetivo

Praticar geração de dados aleatórios, manipulação de listas e utilização de módulos nativos do Python.

> Este programa gera combinações aleatórias e não prevê resultados ou aumenta as chances de ganhar na loteria.
